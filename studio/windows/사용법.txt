MovieClip Studio · Windows 10/11 x64

MovieClip.exe를 더블클릭하세요. 파일 열기를 누르거나 탐색기에서 편집기의 영상을 끌어다 놓기 영역에 영상을 놓으세요. 원본 경로에서 바로 읽습니다.
Windows용 Python과 FFmpeg가 runtime 폴더에 포함되어 있습니다. 폴더를 옮길 때 함께 옮겨 주세요.

내보내기 전에 저장 폴더를 입력하거나 폴더 아이콘으로 선택할 수 있습니다.
기본값으로 저장을 누르면 다음 실행에서도 선택한 저장 폴더를 사용합니다. 최초 기본값은 MovieClip.exe 옆 exports입니다.
영상 옆 휴지통 버튼이나 목록의 Delete 키로 영상을 제거할 수 있습니다.
내보내기 진행 창을 닫은 뒤에도 화면 아래에서 상태를 다시 열 수 있습니다.
작업 표시줄 알림 영역의 MovieClip 아이콘으로 편집기와 결과 폴더를 열거나 앱을 종료할 수 있습니다.

Python 3.13.17, Windows embeddable x64 — https://www.python.org/downloads/release/python-31317/
FFmpeg 9.1 Essentials x64 — https://www.gyan.dev/ffmpeg/builds/
FFmpeg 소스 코드 — https://github.com/FFmpeg/FFmpeg/commit/74e4393595
Microsoft Edge WebView2 SDK — https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.3537.50
라이선스 문서는 runtime 아래 각 구성 요소의 폴더와 WebView2-LICENSE.txt에 있습니다.
