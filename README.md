# MovieClip Studio

FFmpeg로 이어 붙이기, 자르기, 쇼츠 제작을 하는 로컬 영상 편집기입니다.

## Windows 실행

**MovieClip-Windows** 폴더에서 **MovieClip.exe**를 더블클릭합니다. Windows 10/11 x64용입니다. Windows의 Microsoft Edge WebView2 런타임에서 편집기 창을 열며, Python과 FFmpeg는 같은 폴더의 `runtime`에 포함되어 있습니다. 저장 폴더의 기본값은 실행 파일 옆 `exports`입니다. 작업 표시줄 알림 영역의 MovieClip 아이콘으로 앱을 종료할 수 있습니다.

## WSL 또는 Linux에서 실행

Windows 탐색기에서 **MovieClip.cmd**를 더블클릭합니다. 기본 WSL 배포판에서 편집 엔진을 시작하고 Edge 또는 Chrome에서 앱 창을 엽니다. 처음 실행하기 전에 WSL에 `python3`, `ffmpeg`, `ffprobe`가 준비되어 있어야 합니다. Ubuntu에서는 `sudo apt install python3 ffmpeg`로 설치할 수 있습니다.

WSL이나 Linux에서 직접 실행하려면 이 폴더에서 `python3 -B movieclip_studio.py`를 실행한 뒤 브라우저에서 [MovieClip Studio](http://127.0.0.1:8765/)를 엽니다.

## 편집

- **가져오기** · **파일 열기**로 여러 영상을 선택하거나, 탐색기에서 앱 창으로 끌어다 놓습니다. Windows 앱에서 **파일 열기**로 고르거나 편집기의 **영상을 끌어다 놓기** 영역에 파일을 놓으면 원본 경로에서 읽습니다. WSL 또는 Linux에서 일반 브라우저로 연 경우에는 파일이 로컬 임시 폴더에 복사됩니다. 폴더 아이콘으로 전체 파일 경로를 직접 입력하는 방법도 있습니다. 영상 옆 휴지통 버튼으로 목록에서 제거하거나, 목록에서 영상을 선택하고 Delete 키를 누릅니다.
- **자르기** · 타임라인에서 위치를 골라 시작과 끝을 지정하거나 시간을 직접 입력합니다. 빠른 자르기는 스트림을 복사하며 지정한 시작점 앞의 키프레임부터 포함할 수 있습니다. 정밀하게 자르기는 지정한 구간을 다시 인코딩합니다. 두 파일로 분할은 한 위치의 앞뒤를 별도 파일로 저장합니다.
- **이어 붙이기** · 체크한 영상을 미디어 목록 순서대로 연결합니다. 영상을 선택한 뒤 목록 아래 화살표로 순서를 바꿀 수 있습니다. 스트림 복사 방식이므로 코덱, 해상도, 트랙 구성이 같은 영상이 필요합니다.
- **쇼츠** · 선택한 구간의 중앙 4:3 화면을 1080 × 1920 MP4로 내보냅니다. 미리보기의 가이드로 잘리는 영역을 확인할 수 있습니다.
- **내보내기** · 파일 이름과 **저장 폴더**를 입력하고 **내보내기**를 누릅니다. Windows 앱에서는 폴더 아이콘으로 저장 위치를 고를 수 있습니다. **기본값으로 저장**을 누르면 다음 실행에서도 그 폴더가 선택됩니다. 현재 경로를 임시로 바꿨다면 **기본값 사용**으로 돌아갈 수 있습니다. 내보내기 창을 닫아도 작업은 계속되며, 화면 아래에서 상태와 결과를 다시 열 수 있습니다. 완료 화면에 실제 저장 경로가 표시됩니다. 이름이 같은 파일은 번호를 붙여 저장합니다.

오디오가 여러 개 있으면 목록에서 원하는 트랙을 선택할 수 있습니다. 기존 스크립트에 맞춰 자르기는 3번, 쇼츠는 2번 트랙이 있으면 기본으로 선택합니다. 브라우저에서 재생할 수 없는 영상은 타임라인의 해당 위치를 정지 프레임으로 미리 볼 수 있습니다.
